# Avito DS Bootcamp — ориентация текстового кропа (0° / 180°)

Решение: `avito_orientation_solution.ipynb`. Результат: **1 − Brier = 0.9014677** (Brier = 0.0985323).

## Подход (кратко)

**Модель.** Компактная CNN (5 свёрток + BN, 183 665 параметров), вход — градации серого 48×192 с
нормировкой контраста на картинку. Выход антисимметричный: `z(x) = (f(x) − f(rot180(x)))/2`,
поэтому `p(x) + p(rot180(x)) = 1` выполняется по построению. Внешних предобученных моделей нет.

**Данные.** Обучающих данных нет, поэтому используется синтетический генератор текстовых кропов
(рус/англ слова, цены, телефоны, артикулы; 16 шрифтов; разные пропорции, перспектива, блюр, шум, JPEG).
Ориентация известна по построению: часть картинок поворачивается на 180°. На каждой эпохе генерируются
новые примеры (16 000), обучение 12 эпох, AdamW + OneCycle, label smoothing 0.02.

**Валидация.** Размеченных реальных данных нет, поэтому валидация синтетическая: две фиксированные выборки
по 2 000 примеров — «лёгкая» (те же искажения, что в обучении) и «жёсткая» (мельче, размытее, сильнее
шум/JPEG/перспектива), не пересекающиеся с train по seed. После калибровки: лёгкая — 1−Brier 0.985 (acc 0.981),
жёсткая — 0.930 (acc 0.901). Жёсткая выборка используется как прокси сдвига домена: на ней подбирается
температура (T = 0.70) и сравниваются варианты. Итог на тесте (платформа): 1−Brier = 0.9015.
Разрыв между синтетической и реальной оценкой ожидаем из-за domain gap.

**Что пробовали.**
- Калибровка температурой на жёсткой валидации: 1−Brier 0.9281 → 0.9300 (жёсткая), 0.9827 → 0.9846 (лёгкая).
- Клиппинг вероятностей в [0.03, 0.97] (Brier сильно штрафует уверенные ошибки).
- TTA (зум 0.92 и паддинг 8%) с усреднением логитов.
- Label smoothing против самоуверенности.

**Ограничения.** Синтетика не покрывает все шрифты и логотипы реальных объявлений; строки из симметричных
символов («0», «8», «О», «Х») принципиально неоднозначны, для них ожидаются вероятности около 0.5.

## Что нужно
- Python 3.10+ (разработано на 3.14.2), Jupyter

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для GPU установите сборку `torch` с CUDA. Обучение проводилось на CPU, и по идеи гпу не даст сильного прироста из-за того, что в основном время уходит на генерацию синтетики

## Данные
Положите рядом с ноутбуком (или поправьте пути в ячейке «КОНФИГУРАЦИЯ»):
```
./test/images/ # тестовые кропы (поиск рекурсивный, структура подпапок не важна)
```
Файлы находятся по `image_id` (с расширением или без). Если файл не найден, ноутбук остановится с понятной ошибкой.
Внешние данные и интернет не нужны. шрифты берутся из пакета `matplotlib`, синтетика генерируется на лету.

## Запуск
Открыть ноутбук и выполнить Run All:
На выходе: `submission.csv` (колонки `image_id`, `p_180`) и `orientation_model.pt` (веса).

**Время:** ~4 мин/эпоха × 12 эпох ≈ 45–50 мин на CPU. Узкое место — генерация синтетики на CPU, а не сама сеть, поэтому гпу, опять же, слабо ускорит обучение.

**Быстрый запуск без обучения:**
`LOAD_WEIGHTS_IF_EXIST = True` — обучение пропустится, инференс займёт пару минут.
